# Deltamod CLI
An addon to be used with Deltamod; use this to manage your mod projects and create `meta.json` and `modding.xml` files with a command line tool!

## Available commands
These are the available commands:
```
app - Opens the Deltamod desktop app if installed.
init - Initializes a new Deltamod meta.json file in the current directory.
import - Imports the Deltamod project to the Deltamod desktop app.
inspect - Inspects the current Deltamod project and displays its name and version.
xml - Run the XML editor
```
